PsychoPy is a freely available open-source software tool (created by Jonathan Peirce) that can allow you to program experiments for psychology and linguistics. This tutorial will provide you with the basic principles of designing a simple experiment using PsychoPy using its builder interface. Following this tutorial, you will be able to build an experiment on your own laptop ready for data collection. Participants who will attend this tutorial are kindly asked to install PsychoPy beforehand.
